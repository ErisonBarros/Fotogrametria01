# DEFINIÇÕES DE FOTOGRAMETRIAUntitled



| **Outras Definições  FOTOGRAMETRIA** | Embora originalmente a Fotogrametria se ocupasse de analisar fotografias, a definição englobou dados provenientes de sensores remotos. Na definição a seguir, inclui duas áreas distintas:                            |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|                                      | fotogrametria (métrica) - sentido mais restrito, referindo-se aos métodos de obtenção de dados quantitativos, como coordenadas, áreas, volumes..., a partir dos quais são elaborados os mapas e cartas topográficas;  |
|                                      | Fotointerpretação - consiste em obter dados qualitativos por meio da análise das fotografias e de imagens de satélite                                                                                                 |
|                                      | Devido ao grande volume de trabalhos nesta área, convencionou-se classificá-la dentro da área de Sensoriamento Remoto.                                                                                                |
