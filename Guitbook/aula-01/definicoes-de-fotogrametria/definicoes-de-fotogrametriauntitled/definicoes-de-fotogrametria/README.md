# DEFINIÇÕES DE FOTOGRAMETRIA

|                          |                                                                                                                                                                                                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| DEFINIÇÃO Andrade (1988) | Fotogrametria é a ciência e tecnologia de obter informações confiáveis através de processos de registro, interpretação e mensuração de imagens. Andrade (1988).                                                                                                                                                                      |
|                          | É uma técnica de medição remota, que permite o estudo e a definição das formas, das dimensões e da posição de objetos no espaço baseando-se em medições realizadas sobre fotografias ou imagens digitais, registradas por intermédio de sensores fotogramétricos aéreos (aerofotogrametria) ou terrestres (fotogrametria terrestre). |
|                          | É a partir da aerofotogrametria que são desenhados os mapas e as cartas topográficas, entre outros produtos correlatos.                                                                                                                                                                                                              |
