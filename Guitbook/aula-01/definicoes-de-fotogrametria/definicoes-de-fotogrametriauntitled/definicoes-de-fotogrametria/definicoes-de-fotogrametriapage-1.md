# DEFINIÇÕES DE FOTOGRAMETRIAPage 1

|                                             |                                                                                                                                             |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **DEFINIÇÃO DE FOTOGRAMETRIA Kraus (2000)** | É a arte e a ciência de determinar a posição e forma de objetos por meio de fotografias. Os resultados das medições fotogramétricas são:    |
|                                             | Números: coordenadas de pontos de objetos num sistema de coordenadas tridimensional (captura de dados digitais);                            |
|                                             | Gráficos: mapas e plantas com detalhes planimétricos e altimétricos: curvas de nível, junto com outras representações gráficas dos objetos; |
|                                             | Imagens: principalmente fotografias ortorretificadas (ortofotos) e mapas derivados desses e, ainda imagens digitais.                        |
