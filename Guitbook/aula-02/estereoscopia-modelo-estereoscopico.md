# Estereoscopia -  Modelo Estereoscópico

* Um modelo é uma representação da realidade.
* Vimos a possibilidade de aplicar os princípios da visão binocular para reconstruir uma imagem tridimensional a partir de duas imagens bidimensionais, sem ter em presença o próprio objeto
* A figura ilustra a separação das retinas, artificialmente para obter o cenário tridimensional.
* Essa imagem é tridimensional que o observador reproduz, é o modelo estereoscópico
