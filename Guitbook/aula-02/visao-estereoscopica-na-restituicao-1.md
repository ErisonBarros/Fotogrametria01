# visão estereoscópica na restituição

* O traçado das feições espaciais vistas no modelo estereoscópico, é chamado de restituição fotogramétrica.
* Atualmente o ambiente do modelo estereoscópico está integrado a um software de registro de coordenadas e de desenho. Conecta-se a cartografia, tendo os dois ambientes integrados (visão estereoscópica e CAD) associados a um sistema de referencia geográfico. Permite-se desta forma que a coleta de feições tridimensionais, convencionalmente chamada de restituição, seja georreferenciada.
